# Начни здесь

Это сайт Ace Games. Он собран так, чтобы им управлял человек через
ИИ-помощника (Claude Code, Codex, Cursor, Copilot, любой другой), не читая
код. Инструкции для помощника уже лежат внутри, на английском, и он их
найдёт сам. Этот файл для человека.

## Что нужно на компьютере

Только Node.js 20 или новее с nodejs.org. Больше ничего: ни базы, ни
аккаунтов, ни ключей для локальной работы.

## Как открыть сайт у себя

Откройте папку проекта в терминале (или попросите помощника) и выполните:

```
npm install
npm run dev
```

Сайт откроется на http://localhost:4321 (если порт занят: `npm run dev -- --port 4400`).

## Первое сообщение помощнику

Скопируйте и отправьте своему ИИ, открыв папку проекта:

> Прочитай AGENTS.md и AI-HANDOVER.md в этом репозитории, затем выполни
> `npm install` и `npm run ship` и скажи мне, что все проверки прошли.
> После этого я буду давать задачи. Прежде чем менять что-либо, смотри
> рецепт в docs/RECIPES.md. После каждого изменения запускай `npm run ship`
> и проверяй страницу в браузере на ширине 375 и 1440 px.

Дальше говорите с ним обычными словами. Примеры задач, которые он уже умеет
делать по рецептам:

- «Добавь новую игру Neon Vault, вот две картинки.»
- «Поменяй RTP у Gold of Ra на 96.2%.»
- «Отметь Blackjack как выпущенную.»
- «Вот логотипы наших операторов, поставь их на сайт.»
- «Мы сертифицированы iTech Labs, работаем на Мальте и в Швеции, впиши это.»
- «Поменяй заголовок на главной.»
- «Разверни сайт в интернете.» (у него есть пошаговая инструкция DEPLOY.md)

## Одно правило, которое стоит знать

На сайте есть места с оранжевым пунктиром: цифры и факты, которых у нас пока
нет (лаборатория сертификации, юрисдикции, число операторов, логотипы). Это
сделано специально. Помощнику запрещено придумывать эти значения; он
попросит их у вас. Полный список в TODO.md. Как только вы даёте настоящее
значение, пунктир исчезает.

## Как понять, что всё в порядке

Команда `npm run ship` собирает сайт и прогоняет полтора десятка проверок: все старые
адреса на месте, ни одной битой ссылки, у каждой картинки есть размер и
подпись, один заголовок на странице, главная легче 1,5 МБ и так далее.
Если в конце все строки начинаются с `PASS`, сайт можно выкладывать. Если
есть `FAIL`, помощник видит, какая проверка упала и почему.

## Где что лежит

| что | где |
| --- | --- |
| правила для помощника | `AGENTS.md` |
| как делать типовые задачи | `AI-HANDOVER.md`, `docs/RECIPES.md` |
| как выложить в интернет | `DEPLOY.md` |
| почему сайт выглядит именно так | `PLAN.md` |
| что ещё нужно от вас | `TODO.md` |
| игры, по одному файлу на игру | `src/content/games/` |
| картинки игр | `src/assets/games/` и `src/assets/heroes/` |
| тексты, меню, контакты, FAQ | `src/data/site.ts` |

## Что специально не сделано

- Форма обратной связи отправляет письма только после того, как в хостинге
  добавлены три секрета (`.env.example`). До этого она честно показывает
  страницу «не подключено».
- Логотипы операторов, номера лицензий, юрисдикции: пусто до ваших данных.
- Политика конфиденциальности всё ещё упоминает старый хостинг Webflow;
  после переезда текст обновляет юрист.
