Vikings Gold is a dynamic slot built on a 5×6 cluster grid, combining cascading wins with persistent Reward Counters and an interactive Runner Bonus Game. The game blends fast cluster action with long-term bonus progression, creating a strong balance between instant wins and accumulated reward potential.

## Core Gameplay

Vikings Gold uses a cluster-style payout system on a 5×6 grid. Wins are formed when 8 or more identical symbols appear anywhere on the field, and symbols do not need to be adjacent. Winning symbols are removed in cascades, allowing new symbols to fall into place and create additional win opportunities within the same round.

## Main Feature

The game features two Special Elements that feed separate Reward Counters. These counters build between spins and later determine the value used in the Runner Bonus Game.

## Bonus Spins & Bonus Game

The bonus is triggered by 4 Scatter symbols, with the Scatter type determining which Reward Counter is activated. Vikings Gold then shifts into the Runner Bonus Game, where players collect coins and avoid obstacles across four consecutive segments. Each collected coin increases the bonus multiplier. The final reward is based on the active Reward Counter, or the combined total if both types are used.

## Multiple Payline Wins

### Extra Feature

Vikings Gold includes two Scatter types and two Reward Counters, adding additional variation to every bonus trigger. If both Scatter types are involved, both counters can be combined to power a larger bonus payout.

## Design & Atmosphere

### BUILDING A PROGRESSION-DRIVEN VIKING SLOT

Vikings Gold was designed around two layers of gameplay: fast cluster wins and persistent bonus progression. The 5×6 grid delivers quick cascades and repeat win potential within a single round. At the same time, Special Elements keep building value in dedicated Reward Counters.

When the bonus is triggered, that stored value powers a Runner-style mini-game with increasing multipliers. This structure gives the slot both immediate action and a strong sense of long-term momentum.
