Read `AGENTS.md` first: it is the contract for this repo (what the site is,
the ten invariants, the design rules). Then `AI-HANDOVER.md` for how to do
every common task, and `docs/RECIPES.md` for paste-ready requests.

Two commands matter:

    npm run dev     work on it, http://localhost:4321
    npm run ship    build and run the parity gates; every gate must pass

`DEPLOY.md` is the deployment runbook. `TODO.md` is everything the owner still
has to supply; never invent values to fill those gaps.
